# Bronfood CRM — сайт-лендинг

Публичный сайт-лендинг для продукта **Bronfood CRM** — веб-системы для создания и обработки
заказов внутри заведения общественного питания (кафе, кофейни, столовые, небольшие рестораны,
фастфуд и точки take-away).

Сайт создан по техническому заданию «Сайт Bronfood CRM» (файл `ТЗ_сайт_Bronfood_CRM_для_ИИ.docx`).

> Сайт описывает **только CRM для внутренней работы заведения**. На сайте намеренно нет карты
> заведений, клиентского каталога, витрины и оплаты еды для конечных потребителей.

## Технологии

- **React 18** + **React Router 6**
- **SCSS modules** (`*.module.scss`) — модульные стили без CSS-фреймворков
- **Vite 5** — сборка и dev-сервер
- Без внешних UI-библиотек: только собственные компоненты

## Запуск

```bash
npm install       # установка зависимостей
npm run dev       # dev-сервер (http://localhost:5173)
npm run build     # production-сборка в ./dist
npm run preview   # предпросмотр собранной версии
```

## Маршруты

| Путь        | Страница                                                   |
| ----------- | ---------------------------------------------------------- |
| `/`         | Лендинг (все секции: первый экран, возможности, цена, FAQ…) |
| `/offer`    | Публичная оферта                                           |
| `/privacy`  | Политика конфиденциальности и обработки персональных данных |
| `/payment`  | Порядок оплаты и возврата                                  |
| `/success`  | Страница подтверждения отправки заявки                     |
| `*`         | Страница 404                                               |

Юридические документы доступны и как страницы сайта, и как файлы `.docx`
(из футера, из блока стоимости и со страниц документов).

## Интеграция формы заявки

Форма валидируется на клиенте (с сохранением введённых данных при ошибке) и защищена
скрытой «ловушкой» для спам-ботов. Адрес приёма заявок задаётся переменной окружения:

```bash
# .env (скопируйте из .env.example)
VITE_APPLICATION_ENDPOINT=https://your-endpoint.example/api/leads
VITE_APPLICATION_FORMAT=json   # json | form
```

- **Если `VITE_APPLICATION_ENDPOINT` задан** — заявка уходит POST-запросом на этот адрес.
- **Если адрес не задан** — форма честно открывает почтовый клиент с уже заполненным письмом
  на `bronfood.main@gmail.com` (временный сценарий, без имитации серверной отправки).

## Контент

- Весь текст сайта собран в `src/data/content.js` и `src/data/legal/*`.
- Палитра: `#FF8A00`, `#FFD09F`, `#21150F`, `#FFFFFF`
  (заданы в `src/styles/_variables.scss`).
- Иллюстрация первого экрана (`HeroMockup`) — схематичный макет очереди заказов.
  Его следует заменить **реальным скриншотом** интерфейса CRM.

## Что необходимо подтвердить владельцу перед публикацией

По требованию ТЗ, перед публикацией нужно согласовать и уточнить:

1. Рабочий URL регистрации или адрес приёма заявок (`VITE_APPLICATION_ENDPOINT`).
2. URL платёжной формы Freedom Pay и допустимость модели предоплаченного баланса CRM.
3. Утверждённый текст публичной оферты (согласование с юристом и платёжным провайдером).
4. Точное правило определения «активной точки»: начало тарификации, отключение, прекращение начислений.
5. Тексты уведомлений о завершении триала и о нулевом балансе.
6. Актуальность контактов и реквизитов (в источниках встречаются разные варианты телефона и адреса сайта).
7. Даты вступления в силу юридических документов.
8. Реальные скриншоты интерфейса CRM вместо схематичного макета.

Юридические документы подлежат обязательной проверке юристом.
На сайте **не публикуются** неподтверждённые отзывы, рейтинги, счётчики клиентов,
сертификаты и заявления об одобрении платёжного провайдера.
